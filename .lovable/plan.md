# לינק אישור הגעה כללי + SMS אוטומטי

## מה נבנה

1. **לינק כללי לאישור הגעה** — כל אירוע יקבל לינק אחד (`/rsvp/join/<טוקן>`) שניתן להפיץ בוואטסאפ/סטטוס/קבוצה. האורח נכנס, ממלא פרטים, ומצטרף לרשימת המוזמנים.
2. **טופס הרשמה עצמית**: שם מלא, טלפון (חובה), מספר מוזמנים, מספר ילדים, צד/קרבה, ואישור הגעה (מגיע / לא מגיע / עוד לא יודע). עיצוב באותו סטייל של דף האישור האישי הקיים.
3. **מניעת כפילויות**: אם הטלפון כבר קיים באירוע — הרשומה הקיימת מתעדכנת במקום ליצור חדשה.
4. **SMS מיד לאחר אישור** — כל מי שמאשר הגעה מקבל מיד SMS עם פרטי האירוע.
5. **SMS בזמן האירוע** — כל מי שאישר הגעה ויש לו טלפון מקבל SMS עם לינק לתת מתנה, בשעת הקבלה של האירוע (או 19:00 אם לא הוגדרה שעה).
6. **באיזור האישי** (הזמנות → ניהול מוזמנים): כרטיס "לינק כללי לאישור הגעה" עם העתקה/שיתוף בוואטסאפ + QR, סימון בטבלה מי נרשם דרך הלינק הכללי, ומעקב שליחות SMS כמו היום.

## טקסטים לשליחה ב-SMS (לאישורך)

**1. מיד אחרי אישור הגעה:**
```
היי {שם}, איזה כיף שאתם באים! 🤍
{שם האירוע}
🗓️ {תאריך} | 🕖 קבלת פנים {שעה}
📍 {שם האולם}, {כתובת}
אישרתם {מספר} מוזמנים{ ו-{מספר} ילדים}.
מחכים לכם לחגוג יחד!
```

**2. בזמן האירוע — לינק למתנה:**
```
{שם}, אנחנו כבר חוגגים ואיזה כיף שאתם איתנו! 🥂
רוצים לברך את {שמות בעלי האירוע} במתנה דיגיטלית?
מהיר, מאובטח ומגיע ישירות אליהם:
{לינק}
באהבה, {שמות בעלי האירוע} 💛
```

אם תרצה שינוי בנוסח — כתוב לי ואעדכן לפני הבנייה.

## פרטים טכניים

- **בסיס נתונים**: הוספת `rsvp_source` (`manual` / `self`) ו-`gift_sms_sent_at` לטבלת `guests`; פונקציית `SECURITY DEFINER` בשם `self_rsvp_join(token, name, phone, guests, children, side, status)` שמבצעת חיפוש-לפי-טלפון ואז INSERT/UPDATE ומחזירה את ה-guest id (הטריגר `restrict_guest_public_update` חוסם עדכון טלפון מהצד הציבורי, לכן העדכון עובר דרך הפונקציה). הטוקן הכללי מבוסס על `events.share_token_general` (ייווצר אם חסר).
- **קדמי**: דף ציבורי חדש `src/pages/rsvp/SelfRSVP.tsx` + route; כרטיס לינק כללי ב-`src/pages/event/RSVP.tsx` / פאנל ההזמנות; עמודת מקור בטבלת RSVP.
- **SMS מיד אחרי אישור**: Edge Function חדשה `send-rsvp-confirmation-sms` (public, ללא JWT) שנקראת בסיום הטופס, שולחת דרך Twilio באותה תשתית של `send-invitation-sms` ומתעדת ב-`guest_invitation_sends`.
- **SMS בזמן האירוע**: Edge Function `send-event-day-gift-sms` שנבדקת כל שעה ב-pg_cron/pg_net, בוחרת אירועים שהיום ושעת הקבלה שלהם הגיעה, ושולחת רק למי שאישר, יש לו טלפון, ו-`gift_sms_sent_at IS NULL` (הגנה מכפילות). הלינק הוא דף המתנה הציבורי הקיים של האירוע.
- כל השליחות נשמרות ב-`guest_invitation_sends` כדי שהמעקב הקיים יציג אותן.
